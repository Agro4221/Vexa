# Security Policy

## Секреты

Не публикуйте API keys, access/refresh tokens, Telegram sessions, Discord tokens, OAuth credentials, локальные базы, model artifacts или другие приватные runtime-данные.

Секреты должны задаваться во время локального запуска и не попадать в Git.

## Недоверенный ввод

Сообщения платформ, веб-контент и другой внешний input следует считать недоверенным. Модельный вывод не должен автоматически получать неограниченное право на выполнение внешних действий.

## Сообщение об уязвимостях

Не размещайте credentials и рабочие exploit-детали в публичных issues. Для чувствительных проблем используйте приватный канал связи с владельцем проекта.
