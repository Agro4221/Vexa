# Contributing

Спасибо за интерес к Vexa.

Vexa — экспериментальный open-source проект в разработке. Особенно полезны исправления, тесты, документация, улучшения интеграций и идеи для надёжности автономного runtime.

## Перед Pull Request

- опишите проблему и предлагаемое изменение;
- по возможности добавьте или обновите тесты;
- не добавляйте credentials, session-файлы, локальные базы или model artifacts;
- сохраняйте разделение между LLM output и выполнением внешних действий.

Для больших архитектурных изменений лучше сначала обсудить их в Issue.
